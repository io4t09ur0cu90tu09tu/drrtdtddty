# Лабораторна робота №1. Варіант 11: Мобільний тариф

## Опис проекту
Проект реалізує обчислення місячної вартості мобільного тарифу у функціональному стилі.
Чисте ядро ізольоване від побічних ефектів, не використовує глобальний стан та не мутує вхідні дані.

## Структура
- `core.py`: Чисте функціональне ядро та типiзацiя.
- `app.py`: Оболонка виводу результатів (I/O).
- `tests/test_core.py`: Pytest-тести.
